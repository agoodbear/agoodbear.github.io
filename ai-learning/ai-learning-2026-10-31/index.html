AI 學習

2026-10-31 AI 學習日誌

今天多數卡是Claude skill，重點寫Kinetic Film的逐格量測流程，以及IG skill宣傳和作者自測之間的落差。

By 急診熊 · Oct 31, 2026 · 1 分鐘閱讀 · AI學習 · Claude Skill · AI影片 · Kinetic Film · Instagram Agent Skill · Higgsfield

今日最有感的事

今天收進來的AI卡有13張，全部是今天收的。大半在講Claude的skill和MCP，其中好幾張都在講「讓AI做短片」。Bear只在一張卡留了註記，就是Scenario的Kinetic Film，所以先從它寫起。另一組是同一個IG工具的兩種介紹方式，放在一起讀，剛好可以練習怎麼看這類工具貼文。

Kinetic Film：影片用程式碼寫，還要逐格量測

Threads帳號ethansavemoneydairy的貼文開頭寫「R.I.P. Higgsfield Katana.」，說有人把Higgsfield Katana的創作流程逆向拆解，做成一套可以下載的Claude Skill，也就是Scenario公開的Kinetic Film。使用者只要用幾行文字描述自己的產品、遊戲或品牌，後面的影片製作流程就交給AI Agent。

官方頁的標語是「Launch films written as code.」整個流程分四段：

  • 節拍分鏡：把簡報轉成分鏡，依BPM排字幕、鏡頭與轉場。
  • 音樂音效：透過Scenario MCP生成。
  • 程式驅動動畫：每部影片其實是一個網頁，在節拍網格上逐幀渲染，再加上真實動態模糊。
  • 逐格品質檢查：渲染完一格一格量。

幫非工程師補一下背景：MCP可以想成讓AI代理接上外部服務的插座，這裡接的是Scenario的音樂音效生成服務；畫面本身則是程式碼在本機算出來的。

真正值得看的是最後那段量測。官方頁列出的檢查包括：靜止畫面比例（結尾前30%，標準是40%以下）、結尾前不能有超過0.6秒的停頓、每10秒約8.5次硬切、4K母帶小於1 GB。官方頁有一句很直白：「A film that parks between hits fails.」意思是節拍之間畫面停住不動的片子就算不及格。這代表「節奏好不好」被拆成可以量的數字，AI做完可以自己對照檢查。

要跑起來需要Claude Code、Scenario MCP、Node 18與Playwright、ffmpeg、Python 3與numpy／OpenCV。動態在本機渲染，音樂音效會扣Scenario點數。

拆解之後要打折的地方

  • 「逆向Katana」是貼文作者的說法，官方頁完全沒提Higgsfield或Katana，這個說法查無根據。
  • skill裡有Opus署名。
  • 下載的ZIP沒有附授權。
  • 官方示範片拿去跑檢查，閃爍那一項是FAIL。
  • 官方的渲染流程這輪沒有實際跑。

Bear的註記只有一句：「逆向工程feedback回skill」。他想做的事很清楚：把這套流程拆開，把量測和節拍這些有用的部分回饋到自己的skill裡。卡片上也記著，/opus-animation目前還沒收過這個skill。

同一天另外兩張卡剛好是Kinetic Film被拿來對比的Higgsfield那一邊：jessielovefood實測Higgsfield MCP接Claude剪片，亨利溫（Henry Wen）的Reel則示範口播稿搭配/tier-list做動畫。三張放在一起，可以看出兩種路線：一種是接上現成的生成服務下指令，一種是讓程式碼逐格把畫面畫出來、再自己量。

Instagram Agent Skill：同一個repo，兩種講法

IG帳號ethanhuang01的Reel標題是「Claude用13個免費skill搞定了Instagram」，列出Reel寫手（「用26個hook公式寫稿，錄之前先幫你的hook打分」）、留言、回覆、主頁評分、週計劃、爆款拆解等功能，完整安裝指南要留言「SKILL」換私訊。

AI郵報的完整文章讀完README，把重點放在另一邊：「作者自己承認：它能幫你篩掉爛開場，卻猜不出哪支會爆紅。」作者Jake Schincariol用74條YouTube Shorts開場做測試：

  • 分辨故意寫爛的開場：AUC 0.83。
  • 從同一創作者的影片裡挑出爆款：只有0.56，「0.50是丟硬幣」。

補個背景：AUC是衡量「分得出好壞」的指標，0.50等於亂猜，越接近1越準。0.83算有用，0.56就跟猜差不多。而且這是小樣本、非Reels的實測，量測腳本也不在專案內，沒辦法重跑。

兩邊對照，還有幾個落差：

  • 不會幫你留言：宣傳寫「幫你去別人的貼文下留言」，README寫「These skills do not post to Instagram.」，實際只產出可複製的草稿，Claude費用另計。
  • 不必等私訊：repo是公開的，MIT授權。
  • 中文可能不準：AI郵報觀察到hookscore.py計詞只認英文字母與數字，中文開場的分數可能失準；不過該報沒有實際執行程式。

更直白地說，宣傳版講「搞定」，作者自己的數據講「擋得掉爛的，猜不中會紅的」。想拿來寫中文IG的人，該先讀的是後者。

同樣誠實的數據也出現在Claude Code Game Studios：作者讓同一份企劃分別先寫1份和30份文件再開發，結果寫最多文件的版本在盲評和試玩都排最後。工具作者願意公開自己的限制，這種repo反而比較值得信任。

亨利溫：口播稿搭配指令讓AI自動剪片

  • 連結: https://www.instagram.com/reel/DfGqdCQyUI7/

簡光正的Grok Bot美食網站流程

  • 連結: https://www.facebook.com/story.php?story_fbid=10165378546304728&id=655004727

unslop：去掉網頁AI味的Claude skill

  • 連結: https://github.com/heydamir/unslop
  • 先審查畫面列出漸層、發光、emoji標籤等問題與位置，再依間距、色彩、圖示、文案、字體、版面、細節、視覺與動效分階段修正；作者Damir Sokolovsky，CC BY 4.0，要在Claude Code裡用。

Pika H3 Flex開放權重影片模型

  • 連結: https://www.threads.com/@aiposthub/post/DfG48j2jdWe
  • AI郵報報導15秒768p有聲影片最快7秒完成核心運算、權重上架Hugging Face；7秒是特定測試條件下的數字，DesignArena排名與官方來源這輪都沒查證。

Gemini互動探索（Immersive Explorations）

  • 連結: https://www.aiposthub.com/gemini-immersive-explorations/
  • 把主題做成可逐層點開的互動場景，例子有噴射引擎、絲路、閃電；依AI Post Hub這篇二手文章，個人帳號免費可用，官方支援語言未列繁體中文，音訊導覽標示即將提供。

Motion Prompt動態效果字典

  • 連結: https://showheyohtaki.github.io/motion-prompt/
  • 每個效果名稱都有會動的範例和提問範例，可把Prompt複製給Claude Code或Codex；貼文寫168種，README寫192個，名稱清單有繁體中文版，MIT授權。

Claude Code Game Studios

  • 連結: https://github.com/Donchitos/Claude-Code-Game-Studios

周大可：Claude Code寫的SVG影音編輯器

ChatGPT學語言的5個提示詞
