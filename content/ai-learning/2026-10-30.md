## 今日最有感的事

今天收進來的AI卡有4張，全部是今天收的，Bear都沒有留註記。其中三張剛好在講同一件事：讓AI幫忙做影片。今天挑兩張對照著寫：Lemo-Opuscar和video-shotcraft。前者把做法講得很清楚，後者的宣傳說法拆解後要打折扣。放在一起看，剛好可以練習怎麼讀這類「AI幫你出片」的貼文。

### Lemo-Opuscar：影片是用程式碼寫出來的

Threads帳號jchuang1977[介紹了Lemo-Opuscar](https://www.threads.com/@jchuang1977/post/DfFQOqTjsnK)，這是開發者Lemomo做的開源Claude Code Skill，定位是「程式碼影片風格工具箱」。GitHub repo的說明寫，裡面收了一批現成風格，也能做出自己的風格；每種風格是一段風格提示詞，加上一支完全由Claude Opus 5.5用程式碼做出來的示範影片，過程沒有用到影片模型。

幫非工程師補一下背景：一般講「AI做影片」，多半是丟一段文字給影片生成模型，讓它直接吐出畫面。Lemo-Opuscar走另一條路，貼文強調它不用AI影片生成模型，也不用現成素材，而是讓Opus 5.5直接寫程式，用Canvas／WebGL一格一格把畫面渲染出來，再配上取樣音樂庫和TTS語音。Canvas和WebGL是瀏覽器裡用來畫圖的技術，TTS則是文字轉語音。貼文附了一支示範影片，封面是「MISSION CLOCK」倒數錶面。

真正值得看的是它的思路：把一支短片當成一段程式來產生，畫面裡的東西都出自程式碼。這套工具先前已經收進影片相關的GitHub repo調查裡，這則貼文本身沒有新的技術細節，收它主要是當作入口。

### video-shotcraft：「一句話出片」要打折

AI平凡人創業學院（@aistart_up）的[貼文](https://www.threads.com/@aistart_up/post/DfGnuYnDqdY)開頭是「留言『宣傳片』，我把video-shotcraft的安裝跟用法，全部傳給你」，接著問：想幫自己的網站或產品做宣傳片，請人做太貴、自己又不會剪？最後一句是「現在跟Claude說一句話，它就幫你做出來」。

拆解下來的結果：

- **工具是真的**：video-shotcraft是Apache授權的GitHub repo，repo裡有Opus 5.5署名。
- **「一句話出片」不實**：實際用起來會先反問需求。
- **星數沒核到**：貼文提到的+1604星沒有核對到。
- **示範影片的來源不明**：這支影片本身用什麼工具做的，查無結果。

更直白地說，這類「留言索取」的貼文，重點在導流，工具值不值得用，要回到repo本身看。會先反問需求其實不算壞事，做宣傳片本來就得先講清楚對象、長度和風格，只是跟「一句話就出來」的期待有落差。

同一天的video-autopilot-kit剛好補上後段：它把剪輯和品質檢查整理成可重跑的流程。Bear在10-29已經讀過這個repo，也把裡面的交付檢查移植到自己的/cut-video和/travel-vlog。三張卡串起來看，「AI做影片」這件事可以拆成三層：用程式碼生成畫面、用提示詞包裝成好上手的工具、用固定流程把關成品。

## 今日收集的資源

**Lemo-Opuscar GitHub repo**
- 連結: https://github.com/lemomo-ai/lemo-opuscar
- Lemomo的開源Claude Code Skill，收了一批用程式碼做片的現成風格，每種附Claude Opus 5.5做的示範影片，想實際試跑就從這裡開始。

**video-autopilot-kit｜影片自動化工具包**
- 連結: https://freetwai.com/development/skills/video-autopilot
- freetwai介紹Hao0321的開源工具包（MIT，v0.23.0），涵蓋長片、Shorts、Reels的規劃與品質檢查和ffmpeg素材處理，完整剪輯流程用Editkin v4；入門範例不需素材也不需ffmpeg，頁面也提醒星數要回GitHub看最新狀態。

**video-autopilot-kit GitHub repo**
- 連結: https://github.com/Hao0321/video-autopilot-kit
- 原始repo，Bear 10-29讀過並把交付檢查移植到自己的剪片流程，之後要對照更新可以回來看。

**Herdr UI｜Herdr daemon的原生視窗客戶端**
- 連結: https://github.com/penso/herdr-gpui
- Fabien Penso用Rust／GPUI寫的開源（Apache-2.0）桌面客戶端，支援macOS、Linux、Windows，可從issue派工、在agent改動的任一行留註記再送回agent，Teleport還能把worktree連同未提交變更和agent sessions搬到另一台SSH主機；README註明與Herdr官方無隸屬關係，需先自行安裝Herdr。

**Herdr官網**
- 連結: https://herdr.dev/
- Herdr本體，自稱是Claude Code、Codex等coding agent的原生工作環境，關掉視窗agent也會繼續跑，是Herdr UI要連的底層。
