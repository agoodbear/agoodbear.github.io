## 今日最有感的事

今天 Anthropic 推出了一個新東西：**可以在雲端跑的 Claude Code session**。以前 Claude Code 一定綁在我這台 Mac 上跑，關掉終端機、闔上筆電，工作就停了；現在可以從 claude.ai/code 開一個跑在 Anthropic 雲端、有自己 git checkout 的隔離 session，我人不在電腦前，它照樣跑。

背景先補一下：對非工程師來說，這差別像是「本來要自己開著電腦煮一鍋東西、人不能離開」，變成「把食譜寄到中央廚房，他們有空就幫你煮好」。聽起來很爽，但我第一個反應不是興奮，是想搞清楚**這鍋東西誰付錢、按什麼算**。

所以今天花最多時間的不是功能，是額度規則。我把三個問題丟給子代理，要它一律用官方文件回答、不准靠記憶：雲端跟本機是不是扣同一池、那筆試用金怎麼算、用完會怎樣。查完的結論是：

- **雲端跟本機扣的是同一池訂閱額度，扣的速度也一樣。** 官方 costs 頁寫得很清楚，雲端的虛擬機不另外收運算費。這代表同一件工作，在雲端跑或在本機跑，吃掉的訂閱額度基本上一樣——不會因為「搬上雲端」就多花錢，也不會因此省錢。
- **那筆試用金只認雲端。** 根據 @ClaudeDevs 9/24 的公告，雲端 session 正式推出、現有訂閱者可以領一次性試用額度，Pro 是 100 美元、Max 是 250 美元。關鍵是這筆錢**只能花在雲端 session、本機用不到**，而且要主動領、期限到 2026/10/7。更直白地說：不去點那個領取，10/7 一過這 250 美元就歸零，等於白放。
- **扣款順序是：先扣試用金 → 再扣 Max 訂閱額度 → 最後才是加購額度。** 最後那層（usage credits）要自己開啟才生效，超過的部分照 API 牌價另收費；沒開的話，訂閱額度用完就乖乖等下一個 5 小時重置。

真正值得看的是這件事背後的分工邏輯。子代理對照官方文件後，幫我分出哪些工作適合搬上雲端：**已經在 GitHub 上、部署走 Vercel／Cloudflare／GitHub Pages 的 web app**，還有**大量平行、只吃 token 的純查證工作**。反過來，綁在本機的那些（Keynote、LINE 的 .edb 解密、本機 Roam 的 port 3333、本機向量庫、whisper、借瀏覽器登入狀態的爬蟲）就一律留在原地——雲端根本碰不到它們。

我拿一個具體例子來驗證這個判斷：部落格上每週要出的《EMCardio weekly》心臟醫學週報。它剛好卡在 W38 沒寫出來（抓料回報成功，但 X 推文的 cookie 又失效，把寫稿前的檢查擋住了），而它的抓料、寫稿、推 GitHub 全部都是「每週重複、只吃 token」的活，正好落在雲端排程（routines）的甜蜜點上。於是我把它拆開改成雲端版：把原本放在本機 `~/scripts` 的寫稿規則搬進 repo（雲端只讀得到 repo 裡的東西）、X 那層改成可以跳過、發布改成自動開 PR，再設一個「只跑一次、補 W38」的排程當驗收。這一步讓我第一次真的體會到，「重複性、不需要我盯著的工作交給雲端」不是口號，是可以今天就動手搬的。

要注意的坑也記一下：雲端**只吃 GitHub repo**，本機還沒 commit 的東西它看不到；預設網路白名單只放套件庫和常見開發網域，要抓外部網站得自己改成 Custom 或 Full；本機那套 skills 和 `~/.claude` 記憶不會自動帶上去，重要規則得寫進 repo 的 `CLAUDE.md`。這些都是 cloud-environments 文件裡講明的限制，搬之前先看清楚，比事後除錯划算。

## 今日收集的資源

**Claude Code on the web（雲端 session 官方說明）**
- 連結: https://code.claude.com/docs/en/claude-code-on-the-web.md
- 說明: 介紹怎麼從 claude.ai/code 開一個跑在 Anthropic 雲端、有自己 git checkout 的隔離 session，不用綁著本機。

**Cloud environments（雲端環境限制）**
- 連結: https://code.claude.com/docs/en/cloud-environments.md
- 說明: 列出雲端環境的限制：預設網路白名單只放套件庫、要抓外部網站得改 Custom／Full；密鑰怎麼放、哪些 MCP 連接器（Gmail、GCal、Drive、Supabase、Vercel）雲端能用。

**Routines（雲端排程）**
- 連結: https://code.claude.com/docs/en/routines.md
- 說明: 雲端排程文件，每個 routine 會開一個全新隔離的雲端 session，可設 cron 週期或指定時間跑一次；每天有啟動次數上限，這是 EMCardio 週報搬雲端要用的機制。

**Costs（計費說明）**
- 連結: https://code.claude.com/docs/en/costs.md
- 說明: 確認雲端跟本機扣同一池訂閱額度、扣的速度一樣，雲端虛擬機不另外收運算費，是今天釐清額度規則最關鍵的一頁。

**@ClaudeDevs：雲端 session 正式推出公告**
- 連結: https://x.com/ClaudeDevs/status/2102871550974427462
- 說明: 官方帳號 9/24 宣布雲端 session 正式推出、現有訂閱者可領一次性試用額度（Pro 100、Max 250 美元）的公告。

**管理付費方案的加購額度（usage credits）**
