## 今日最有感的事

今天收進來的AI卡有九張，都是今天收的。Bear只在一張留了註記：teardown技能，一句「太可愛了，可以評估裝看看」。另一張沒有註記，但很實用：有人讓Claude Code住進Grok Bot的雲端電腦，24小時不關機，還能從手機接手。一張講Claude Code能「做出什麼」，一張講它能「待在哪裡做」，放在一起看剛好互補。

### teardown：把機器做成可以親手拆開的3D網頁

Threads作者SUKA（@yutopenguin）熬夜實測了一個在X上爆紅的免費Claude技能，名字叫teardown，作者是Elvar。它能把各種機器變成「可以親手拆開」的3D模擬器，也就是大家說的爆炸圖。

幫非工程師補一下背景。爆炸圖是工程與教學常見的畫法：把一台機器的零件沿著組裝方向拉開，讓你看清楚每個零件在哪、怎麼組在一起。teardown做的是互動版，而且產物只是一個不到1 MB的網頁：

- 零件會轉，外殼可以剖開
- 每個部位都有一顆按鈕
- 旁邊的儀表會跟著即時跳動

貼文說Elvar兩天做出7台，其中V8引擎那支衝到379萬觀看。SUKA照著做，生出一隻會呼嚕的胖胖貓「麻糬MC-7」，從頭到尾只用Claude Code。配圖特別標出「關鍵一步：先給AI看參考圖」。SUKA的說法是，這種作品過去得湊齊建模師、工程師、動畫師、配音四個人。

分流時已經往下追過：teardown的repo是MIT授權、署名有Opus；V8那支影片已經錄在本機，9段prompt也逐字收下來了。貓那支影片沒有聲音，prompt沒有公開。要注意的是，技能的安裝來源和repo網址，沒有出現在抓到的貼文內文裡，目前也還沒代裝。

真正值得看的是那句「先給AI看參考圖」。這代表做出好看成品的門檻，很大一部分落在你能不能找到一張清楚的參考圖，寫程式反而交給Claude Code。Bear的註記是「太可愛了，可以評估裝看看」，下一步就是確認安裝來源後再試裝。

### Grok Bot雲端電腦：讓Claude Code筆電闔上照樣工作

潘奕兆（@pan_0709）在Threads只貼了一條連結和「可以參考」，指向他在MadebyPan的部落格文章〈免複雜設定！讓Claude Code在Grok Bot 24小時運行、交流〉（2026-10-08）。

前提是Grok Bot給每個帳號一台雲端電腦，筆電闔上照樣工作。他請Grok在上面裝Claude Code CLI，接著遇到兩個問題：

**問題一：看不到Grok跟Claude說了什麼。** Grok轉交需求時會自己加料，對話又看不到。他的解法是每次派工都用`claude --remote-control`在tmux開一段對話，把session連結傳回手機，可以直接接手插話，並把這套做成Grok的Skill。他也要求Grok「只轉述我的需求，不要自己加顏色、做法這類規定」。

**問題二：Claude叫不到Grok。** 他在Grok Bot建Webhook觸發排程，Claude做完或需要瀏覽器操作時就打Webhook，形成雙向派工。實測讓Grok開Threads輸入「測試」但不送出，大約兩分鐘回報完成。

他也比較了另外三種做法的限制：Claude Code Projects無法共用登入狀態；「Mac + Remote Control電腦關了就做不了事」；VPS＋Discord管理比較麻煩。分工上「主要消耗我的Claude額度去做事，Grok Bot的額度就用最便宜的」。另外一個容易踩的坑：Remote Control要用claude.ai帳號登入，API key不能用。

更直白地說，這套架構把Grok當成24小時的總機兼跑腿，真正動腦寫程式的還是Claude Code，人則透過手機隨時插話。
